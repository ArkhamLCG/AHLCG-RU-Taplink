# 🖨️ Распечатки токенов

Коллекция улучшенных токенов для Arkham Horror: The Card Game, созданных участниками сообщества.

## Токены здоровья и рассудка

### Стилизованные токены
- **Классический стиль** - в духе оригинальной игры
- **Минималистичный дизайн** - четкие и читаемые
- **Тематические варианты** - для разных кампаний

### Материалы для печати
- **PDF файлы** - готовые к печати
- **PNG изображения** - для самостоятельной настройки
- **Инструкции по печати** - размеры и материалы

## Токены ресурсов

### Фракционные токены
- **Стилизация под фракции** - уникальный дизайн для каждой
- **Цветовое кодирование** - для быстрого распознавания
- **Разные размеры** - для удобства использования

### Специальные токены
- **Токены опыта** - для отслеживания прогресса
- **Токены ужаса** - для эффектов страха
- **Токены состояний** - для различных эффектов

## Инструкции по изготовлению

### Материалы
- **Плотная бумага** - 200-300 г/м²
- **Ламинация** - для защиты от износа
- **Магнитная основа** - для удобства хранения

### Процесс изготовления
1. Скачайте файлы
2. Распечатайте на плотной бумаге
3. Вырежьте по контуру
4. При необходимости заламинируйте
5. Приклейте на магнитную основу
